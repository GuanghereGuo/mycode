\section{实验目的}

\begin{enumerate}[label=\arabic*.]
    \item 理解 RLC 串联电路的谐振现象，掌握谐振频率的理论计算方法。
    \item 学习使用示波器和信号发生器测量串联谐振电路的幅频特性。
    \item 理解品质因数 \(Q\) 和 \(\SI{3}{\dB}\) 带宽的物理意义，掌握实验测定方法。
    \item 观察不同电阻值对谐振曲线尖锐程度（选择性）的影响。
\end{enumerate}

\section{实验原理}

\subsection{RLC 串联谐振}

在 RLC 串联电路中，电路的复阻抗为
\begin{equation}
    Z = R + j\!\left(\omega L - \frac{1}{\omega C}\right),
\end{equation}
其模为
\begin{equation}
    |Z| = \sqrt{R^{2}+\left(\omega L - \dfrac{1}{\omega C}\right)^{2}}.
\end{equation}
当感抗与容抗相等时，即 \(\omega_{0}L = 1/(\omega_{0}C)\)，电路发生谐振。此时阻抗为纯电阻，且取最小值 \(|Z|_{\min}=R\)，回路电流达到最大值 \(I_{0}=U_{s}/R\)。

谐振角频率和谐振频率分别为
\begin{equation}
    \omega_{0}=\frac{1}{\sqrt{LC}}, \qquad
    f_{0}=\frac{1}{2\pi\sqrt{LC}}.
\end{equation}

代入本实验参数 \(L=\SI{100}{\milli\henry}\)、\(C=\SI{0.1}{\micro\farad}\)，得
\begin{equation}
    f_{0}=\frac{1}{2\pi\sqrt{0.1\times 0.1\times 10^{-6}}}
         =\frac{1}{2\pi\times 10^{-4}}
         \approx \SI{1591.5}{\hertz}.
\end{equation}

谐振时，电感电压与电容电压大小相等、方向相反，可以远大于电源电压，出现电压谐振现象。

\subsection{品质因数与带宽}

品质因数 \(Q\) 表征谐振回路的选择性，定义为
\begin{equation}
    Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{\omega_{0}L}{R} = \frac{1}{\omega_{0}CR} = \frac{f_{0}}{\Delta f},
\end{equation}
其中 \(\Delta f = f_{2}-f_{1}\) 为 \(\SI{3}{\dB}\) 带宽，\(f_{1}\) 和 \(f_{2}\) 分别是电阻电压 \(U_{R}\) 下降到峰值的 \(1/\sqrt{2}\) 倍所对应的下截止频率和上截止频率。

代入本实验参数：
\begin{align}
    R=\SI{100}{\ohm} &:\quad Q = \frac{1}{100}\sqrt{\frac{0.1}{0.1\times 10^{-6}}} = \frac{1000}{100} = 10, \\
    R=\SI{1000}{\ohm} &:\quad Q = \frac{1000}{1000} = 1.
\end{align}

\(Q\) 值越大，谐振曲线越尖锐，电路选择性越好；\(Q\) 值越小，曲线越平坦，通频带越宽。

\section{实验步骤}

\begin{enumerate}[label=\arabic*.]
    \item 搭建 RLC 串联电路：信号发生器输出端依次串联电阻 \(R=\SI{100}{\ohm}\)、十进制电感箱（\(L=\SI{100}{\milli\henry}\)）和电容 \(C=\SI{0.1}{\micro\farad}\)，构成串联回路。信号发生器设置为正弦波输出，幅值 \(\SI{2}{V_{pp}}\)。
    \item 用示波器探头接在电阻两端，测量电阻电压 \(U_{R}\)。由于串联电路中电流处处相等，\(U_{R}\) 的变化直接反映回路电流的变化。
    \item 从 \(\SI{1.0}{\kilo\hertz}\) 起逐步增大信号频率至 \(\SI{2.2}{\kilo\hertz}\)，每隔 \(\SI{100}{\hertz}\) 记录一次 \(U_{R}\)。在 \(U_{R}\) 出现明显增大的频率附近加密测量点，精确确定谐振频率（\(U_{R}\) 最大值对应频率）。
    \item 在谐振频率处观察并拍摄示波器波形。
    \item 将电阻更换为 \(R=\SI{1000}{\ohm}\)，重复上述频率扫描。由于 \(Q\) 值较小、带宽较大，测量范围扩展至 \(\SI{0.5}{\kilo\hertz}\sim\SI{10}{\kilo\hertz}\)，在远离谐振频率处适当增大频率间隔。
    \item 记录全部数据，拆除电路，整理实验台。
\end{enumerate}

\subsection{品质因数与 \(\SI{3}{\dB}\) 带宽}

\(\SI{3}{\dB}\) 带宽的测定方法为：找到 \(U_{R}\) 下降至峰值的 \(1/\sqrt{2}\) 倍所对应的上、下截止频率 \(f_{1}\) 和 \(f_{2}\)，带宽 \(\Delta f = f_{2}-f_{1}\)，品质因数 \(Q_{\exp}=f_{0}/\Delta f\)。

\subsubsection{\(R=\SI{100}{\ohm}\)}

峰值 \(U_{R,\max}=\SI{2.42}{\volt}\)，\(\SI{3}{\dB}\) 判据值为
\begin{equation}
    U_{R,\max}/\sqrt{2} = 2.42/1.414 \approx \SI{1.71}{\volt}.
\end{equation}

由表~\ref{e4-tab:data-r100}，在低频侧 \(\SI{1.4}{\kilo\hertz}\) 处 \(U_{R}=\SI{1.49}{\volt}<\SI{1.71}{\volt}\)，\(\SI{1.5}{\kilo\hertz}\) 处 \(U_{R}=\SI{2.07}{\volt}>\SI{1.71}{\volt}\)，线性插值得下截止频率
\begin{equation}
    f_{1} \approx 1.4 + \frac{1.71-1.49}{2.07-1.49}\times 0.1 = 1.4 + 0.038 \approx \SI{1.438}{\kilo\hertz}.
\end{equation}

在高频侧 \(\SI{1.7}{\kilo\hertz}\) 处 \(U_{R}=\SI{2.07}{\volt}>\SI{1.71}{\volt}\)，\(\SI{1.8}{\kilo\hertz}\) 处 \(U_{R}=\SI{1.63}{\volt}<\SI{1.71}{\volt}\)，线性插值得上截止频率
\begin{equation}
    f_{2} \approx 1.7 + \frac{2.07-1.71}{2.07-1.63}\times 0.1 = 1.7 + 0.082 \approx \SI{1.782}{\kilo\hertz}.
\end{equation}

因此带宽和品质因数为
\begin{align}
    \Delta f &= f_{2}-f_{1} = 1782-1438 = \SI{344}{\hertz}, \\
    Q_{\exp} &= \frac{f_{0}}{\Delta f} = \frac{1610}{344} \approx 4.68.
\end{align}

理论 \(Q=10\)，实测 \(Q_{\exp}\approx 4.68\)，差异较大。

\subsubsection{\(R=\SI{1000}{\ohm}\)}

峰值 \(U_{R,\max}=\SI{4.58}{\volt}\)，\(\SI{3}{\dB}\) 判据值为
\begin{equation}
    U_{R,\max}/\sqrt{2} = 4.58/1.414 \approx \SI{3.24}{\volt}.
\end{equation}

在低频侧 \(\SI{1.0}{\kilo\hertz}\) 处 \(U_{R}=\SI{3.23}{\volt}\approx\SI{3.24}{\volt}\)，因此 \(f_{1}\approx\SI{1.0}{\kilo\hertz}\)。

在高频侧 \(\SI{2.1}{\kilo\hertz}\) 处 \(U_{R}=\SI{4.22}{\volt}>\SI{3.24}{\volt}\)，\(\SI{3.0}{\kilo\hertz}\) 处 \(U_{R}=\SI{3.02}{\volt}<\SI{3.24}{\volt}\)，线性插值得
\begin{equation}
    f_{2} \approx 2.1 + \frac{4.22-3.24}{4.22-3.02}\times 0.9 = 2.1 + 0.735 \approx \SI{2.835}{\kilo\hertz}.
\end{equation}

因此带宽和品质因数为
\begin{align}
    \Delta f &= f_{2}-f_{1} = 2835-1000 = \SI{1835}{\hertz}, \\
    Q_{\exp} &= \frac{f_{0}}{\Delta f} = \frac{1700}{1835} \approx 0.93.
\end{align}

理论 \(Q=1\)，实测 \(Q_{\exp}\approx 0.93\)，吻合较好。

\subsection{不同 \(R\) 值对选择性的影响}

实验结果清楚地表明：
\begin{itemize}
    \item \(R=\SI{100}{\ohm}\)（实际约 \(\SI{210}{\ohm}\)）时，谐振峰尖锐，\(\SI{3}{\dB}\) 带宽约 \(\SI{344}{\hertz}\)，选择性较好。
    \item \(R=\SI{1000}{\ohm}\)（实际约 \(\SI{1110}{\ohm}\)）时，谐振峰平缓，\(\SI{3}{\dB}\) 带宽约 \(\SI{1835}{\hertz}\)，选择性较差。
\end{itemize}

这与理论一致：串联谐振回路的品质因数 \(Q\) 与电阻成反比，\(R\) 越小，\(Q\) 越大，谐振曲线越尖锐，频率选择性越好。

\subsection{误差来源分析}

\(R=\SI{100}{\ohm}\) 下实测 \(Q_{\exp}\approx 4.68\) 远低于理论值 \(Q=10\)，说明回路中存在不可忽略的寄生电阻。寄生电阻主要来自十进制电感箱的直流电阻、信号发生器的输出阻抗（通常 \(\SI{50}{\ohm}\)）以及导线的接触电阻。设总寄生电阻为 \(R_{p}\)，则回路实际电阻为 \(R+R_{p}\)，实际品质因数应为
\begin{equation}
    Q_{\text{actual}} = \frac{1}{R+R_{p}}\sqrt{\frac{L}{C}}.
\end{equation}

利用两组实验在谐振频率处的峰值数据联立求解：
\begin{equation}
    \begin{cases}
    U_{R,\max}^{(1)} = V_{s}\cdot\dfrac{R_{1}}{R_{1}+R_{p}} = \SI{2.42}{\volt}, \\[6pt]
    U_{R,\max}^{(2)} = V_{s}\cdot\dfrac{R_{2}}{R_{2}+R_{p}} = \SI{4.58}{\volt},
    \end{cases}
\end{equation}
其中 \(R_{1}=\SI{100}{\ohm}\)，\(R_{2}=\SI{1000}{\ohm}\)。解得 \(R_{p}\approx\SI{110}{\ohm}\)，\(V_{s}\approx\SI{5.08}{\volt}\)。

该估算值与从 \(Q_{\exp}\) 反推的结果一致：由 \(Q_{\exp}\approx 4.68\) 可得 \(R+R_{p}=1000/4.68\approx\SI{214}{\ohm}\)，即 \(R_{p}\approx\SI{114}{\ohm}\)，两种方法所得结果吻合。

当 \(R=\SI{1000}{\ohm}\) 时，\(R_{p}\approx\SI{110}{\ohm}\) 仅占总电阻的 \(10\%\) 左右，理论上此时
\begin{equation}
    Q_{\text{actual}} = \frac{1000}{1000+110} \approx 0.90,
\end{equation}
与实测 \(Q_{\exp}\approx 0.93\) 基本一致，进一步佐证了总寄生电阻约 \(\SI{110}{\ohm}\) 的估算。

考虑 \(R_{p}\approx\SI{110}{\ohm}\) 后，回路实际等效电阻为 \(R_{\text{eff}}=R+R_{p}\)。图~\ref{e4-fig:corrected-response} 将修正后的理论曲线与实测数据叠加对比，可见修正曲线与实测数据的吻合度远优于理想理论曲线。

具体误差来源如下：

\begin{enumerate}[label=\arabic*.]
    \item 十进制电感箱存在较大的直流电阻，是总寄生电阻 \(R_{p}\approx\SI{110}{\ohm}\) 的主要组成部分，导致 \(R=\SI{100}{\ohm}\) 下实测 \(Q\) 远低于理论值。
    \item 信号发生器具有内部输出阻抗（通常 \(\SI{50}{\ohm}\)），等效串入回路，进一步增大回路总电阻。
    \item 电容和电感的实际值与标称值存在偏差，影响实际谐振频率。
    \item 示波器探头的输入阻抗和分布电容会对被测电路产生负载效应，在高频段影响更显著。
    \item 频率调节和电压读数均存在分辨率限制，特别是 \(Q\) 较低时谐振峰平坦，峰值频率的判定不够精确。
    \item 面包板和导线的接触电阻增加了回路的总电阻。
\end{enumerate}

综上，本实验测量了两组不同电阻下 RLC 串联谐振电路的幅频特性。实测谐振频率与理论值接近，\(R=\SI{100}{\ohm}\) 下相对误差仅 \(1.16\%\)。品质因数方面，\(R=\SI{1000}{\ohm}\) 的实测 \(Q\) 与理论值吻合良好，\(R=\SI{100}{\ohm}\) 下实测 \(Q\) 偏低的主要原因是回路中约 \(\SI{110}{\ohm}\) 的总寄生电阻（电感箱直流电阻为主）。实验结果定性地验证了串联谐振电路的基本特性：\(R\) 越小，\(Q\) 越大，谐振曲线越尖锐，电路选择性越好。
