● 基于项目约定，我对电基实验报告的理解可以归纳为以下几点：

  1. 预习 vs 正式，两份完全不同的文件
  - 预习报告（preview.tex）：简洁封面，重心在「实验原理」（占 80%）——理论推导 +
  Multisim 仿真。
  - 正式报告（report.tex）：校徽正式封面，按教师 6
  个评分项组织（目的/原理/器件/步骤/数据/分析）。
  - 二者模板不通用，不能混写。

  2. 图片有严格的"身份"区分
  - 实物照片、示波器截图、原始数据记录页、教师签名页——正式报告专属，不可被
  PPT/参考图替代。
  - Multisim 仿真图——优先用本实验目录的，缺失才从 requirements/extracted_images/
   选取对应电路。
  - 用户已命名的图按名称判断用途；未命名微信图默认是 PPT
  实拍，不直接进正式报告。

  3. 数据必须"上桌"
  - 照片里的数据要整理成表格，看不清的填 xx，绝不编造。
  - 参考方向乱了先按电路拓扑统一，再处理正负号。

  4. 数据分析要"定制化"
  - 围绕本实验目的：理论 vs 仿真 vs 实测三方对比，算误差，分析偏差来源。
  - 不能套用其他实验的分析模板。

  5. 工作流默认自主
  - 材料齐全就直接写完并 latexmk -xelatex -outdir=build 编译；
  - 只有关键数据缺失、参考方向无法判断、图片性质冲突时才停下来问。

  6. 排版细节
  - ctexart + xelatex；不写目录、不写摘要；参考文献接在正文末尾不单独成页；积极
  用三线表和子图。

  简而言之：模板分清楚、图片对得上、数据进表格、分析贴本实验——这四件事做对，一份
  合格的电基报告基本就成了。

     封面

     - 校徽 logo1.png + "电路基础 / 实验报告"

     1. 实验目的 (10分)

     4 条，源自 PPT 和预习要求：
     1. 理解 RLC 串联电路的谐振现象，掌握谐振频率的理论计算
     2. 学习使用示波器和信号发生器测量串联谐振电路的幅频特性
     3. 理解品质因数 Q 和 3dB 带宽的概念，掌握实验测量方法
     4. 观察不同电阻对谐振曲线尖锐程度（选择性）的影响

     2. 实验原理 (20分)

     2.1 RLC 串联谐振

     - 串联 RLC 电路阻抗：$Z = R + j(\omega L - 1/\omega C)$
     - 谐振条件：$\omega_0 L = 1/\omega_0 C$，即 $f_0 = \frac{1}{2\pi\sqrt{LC}}$
     - 谐振时 Z = R（纯阻性，最小），电流最大 $I_0 = U_s / R$
     - 代入参数：$f_0 = \frac{1}{2\pi\sqrt{0.1 \times 0.1 \times 10^{-6}}}
     \approx 1591.5,\text{Hz}$

     2.2 品质因数与带宽

     - $Q = \frac{1}{R}\sqrt{\frac{L}{C}} = \frac{f_0}{\Delta f}$
     - R=100Ω 理论 Q=10，R=1000Ω 理论 Q=1
     - 3dB 带宽：$U_R$ 下降到峰值的 $1/\sqrt{2}$ 处对应的频率范围

     2.3 Multisim 仿真

     - 电路图：使用 image16.png（extracted_images），R=100Ω + L=100mH + C=0.1μF
     串联，XMM1 测 U_R
     - 仿真频率响应：使用 image17.png（R=100Ω，尖锐峰）和
     image18.png（R=1000Ω，宽峰）
     - 从仿真曲线中提取仿真谐振频率和峰值，供后续对比

     3. 实验器件 (10分)

     - RIGOL DG922 函数信号发生器 ×1
     - RIGOL DHO1204 数字示波器 ×1
     - RIGOL DM858 数字万用表 ×1
     - 十进制电感箱 ×1（设置 L=100mH）
     - 电阻：100Ω ×1、1000Ω ×1
     - 电容：0.1μF ×1
     - 面包板 ×1、导线若干

     4. 实验步骤 (10分)

     约 5-6 步，基于 PPT7/PPT8 内容：
     1. 搭建 RLC 串联电路（R=100Ω, L=100mH,
     C=0.1μF），信号发生器输出正弦波，设置 2Vpp
     2. 示波器探头接电阻两端测量 U_R
     3. 从低频到高频扫描，在 1.0–2.2 kHz 范围内逐步调节频率，记录各频率点的 U_R
     4. 找到 U_R 最大值对应的频率即为实测谐振频率
     5. 更换 R=1000Ω，重复频率扫描（扩展到 0.5–10 kHz）
     6. 在谐振频率处拍摄示波器波形

     6. 数据分析 (20分)

     6.1 谐振频率对比

     ┌──────┬───────────┬─────────────┬──────────────┐
     │ 项目 │  理论值   │ R=100Ω 实测 │ R=1000Ω 实测 │
     ├──────┼───────────┼─────────────┼──────────────┤
     │ f₀   │ 1591.5 Hz │ 1610 Hz     │ 1700 Hz      │
     └──────┴───────────┴─────────────┴──────────────┘

     计算相对误差。

     6.2 品质因数与 3dB 带宽

     通过插值法从数据中找 3dB 点：
     - R=100Ω：U_R(f₀)/√2 ≈ 1.71V → 插值得 f₁ ≈ 1.44 kHz, f₂ ≈ 1.78 kHz → BW ≈
     340 Hz → Q_exp ≈ 4.7（理论 Q=10）
     - R=1000Ω：U_R(f₀)/√2 ≈ 3.24V → 插值得 f₁ ≈ 1.0 kHz, f₂ ≈ 2.8 kHz → BW ≈
     1800 Hz → Q_exp ≈ 0.9（理论 Q=1）

     分析 R=100Ω 下 Q 偏差大的原因：电感箱自身直流电阻（估计 R_L ≈
     100–120Ω），使实际电阻约为 200–220Ω。

     6.3 不同 R 值对选择性的影响

     - R 越小，谐振峰越尖锐，Q 越大，选择性越好
     - R=100Ω 曲线陡峭（但因电感内阻实际 Q 不及理论）
     - R=1000Ω 曲线平缓，带宽大，选择性差

     6.4 误差来源分析

     1. 电感箱存在较大直流电阻（最主要因素），使实际 R 远大于标称值
     2. 信号发生器具有输出阻抗（通常 50Ω），等效串入回路
     3. 电容实际容值与标称值有偏差
     4. 示波器探头输入阻抗和分布电容对高频测量有影响
     5. 频率读数精度和电压读数精度有限
     6. 面包板接触电阻
