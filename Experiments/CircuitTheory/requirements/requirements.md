# 电路基础实验报告要求

## 预习报告格式（实验前完成）

封面：
```
第X次实验验证XX定理
组名：第X组  姓名：XXXXXX  学号：XXXXX
```

正文结构：
- **(10分) 实验目的**
- **(80分) 实验原理** —— 预习报告重点
  - 理论分析（电路原理、公式推导）
  - Multisim 仿真图（必须插入，其它形式图一律扣分）
  - Multisim 仿真结果
- **(10分) 实验器件**
  - 列出器件名称、参数

## 实验报告格式（实验后完成）

封面：
```
第X次实验验证XX定理
组名：第X组  姓名：XXXXXX  学号：XXXXX
```

正文结构：
- **(10分) 实验目的**
- **(20分) 实验原理**
  - 理论分析
  - Multisim 仿真图（必须插入，不得和老师图一模一样）
- **(10分) 实验器件**
- **(10分) 实验步骤**
- **(10分) 实验数据**
- **(20分) 数据分析**
  - 实验数据与理论公式对比
  - 不同测量方法比较
  - 误差来源分析

## 文件组织

每个实验目录结构：
```
N. topic_name/
  ├── preview.tex    # 预习报告（实验前完成）
  ├── report.tex     # 实验报告（实验后完成）
  └── figures/       # 截图和照片
```

## 图片使用规则

- **Multisim 仿真图**：使用从 `requirements/extracted_images/` 提取的图片
- **实物照片、示波器截图等**：由用户另行提供，不能使用提取的图片

## 教师格式要求（微信群消息）

1. 每个实验单独一份文档
2. 保留原始数据页
3. 保留教师签名页
4. 文件命名格式：`姓名_学号_电路基础实验报告_N`
5. 提交两份：一份合并（全部实验），一份单个实验

## 格式细节

- **不要写目录**
- **不要写摘要**
- 参考文献放在报告最后面（不单独占一页）
- 页码使用 LaTeX 原生格式
