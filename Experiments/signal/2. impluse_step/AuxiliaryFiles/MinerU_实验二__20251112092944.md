# 三、实验原理

以单位冲激信号  $\delta(t)$  作为激励，LTI连续系统产生的零状态响应称为单位冲激响应，简称冲激响应，记为  $h(t)$  。冲激响应示意图如图2-1：

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/a2971af67f5c3b7236eda0dfb949e450d579fd5dd71c0a978a78b19a46e5290f.jpg)  
图2-1冲激响应示意图

以单位阶跃信号  $u(t)$  作为激励，LTI 连续系统产生的零状态响应称为单位阶跃响应，简称阶跃响应，记为  $g(t)$  。阶跃响应示意图如图 2-2:

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/dbd5e369c0c18db59f2a0e519f22c7088cc88dd3728b2a1679c203421eda9f2c.jpg)  
图2-2阶跃响应示意图

阶跃激励与阶跃响应的关系简单地表示为！

$$
g (t) = H [ u (t) ] \text {或 者} u (t) \rightarrow g (t)
$$

如图 2-3 所示为 RLC 串联电路的阶跃响应与冲激响应实验电路图, 其响应有以下三种状态:

1、当电阻  $R > 2\sqrt{\frac{L}{C}}$  时为过阻尼状态；  
2、当电阻  $R = 2\sqrt{\frac{L}{C}}$  时为临界阻尼状态；  
3、当电阻  $R < 2\sqrt{\frac{L}{C}}$  时为欠阻尼状态；

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/20bbdc6af8a24e7e7cbdeac5a3cd1070b1f1b13db8fb501fef3554126dd2e8c8.jpg)  
图2-3(a) 阶跃响应电路连接示意图

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/c00791f25b015a7039cdbf29bc7519b16e27c40fcc0353d8a9ccf5374e26ed65.jpg)  
图2-3(b)冲激响应电路连接示意图

响应的动态指标定义如下：

上升时间  $t_r$  :  $y(t)$  从 0 到第一次达到稳态值  $y(\infty)$  所需的时间。

峰值时间  $t_p: y(t)$  从0上升到  $y_{\mathrm{max}}$  所需的时间。

调节时间  $t_{s}:y(t)$  的振荡包络线进入到稳态值的  $+5\%$  误差范围所需的时间。

最大超调量  $\delta_{p}:\delta_{p} = \frac{y_{\max} - y(\infty)}{y(\infty)}\times 100\%$

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/38a6c43ad22ca06f2b8522ff1997e35f3a2d2b3678575683e60aa89c179f4969.jpg)  
图2-4响应指标示意图

冲激信号是阶跃信号的导数，即  $g(t) = \int_{0^{-}}^{t} h(\tau) d\tau$ ，所以对线性时不变电路冲激响应也是阶跃响应的导数。为了便于用示波器观察响应波形，实验中用周期方波代替阶跃信号。而用周期方波通过微分电路后得到的尖顶脉冲代替冲激信号。

# 2、分析实验结果，说明电路参数变化对状态的影响。

# （1）阶跃响应

当系统的  $R$  由小至大变化的时候，电路由欠阻尼状态、变化到临界阻尼状态、以及过阻尼状态。对于输入信号几乎无影响，即激励信号幅度  $(A = 975mV)$  、周期  $(T = 2ms)$  、脉宽  $(T_{1} = 1ms)$  基本不变；输出信号即响应幅度逐步略微下降  $(A = 969,962,940mV)$ ，周期  $(T = 2ms)$  、脉宽  $(T_{1} = 1ms)$  基本不变，时间常数增大  $(\tau = 34,70,286\mu s)$  。

# （2）冲激响应

当系统的  $R$  由小至大变化的时候，电路由欠阻尼状态、变化到临界阻尼状态、以及过阻尼状态。对于输入信号几乎无影响，即激励信号幅度  $(A = 1.988V)$  、周期  $(T = 2ms)$  、脉宽基本不变  $(T_{1} = 1ms)$  ；输出信号即响应幅度下降明显  $(A = 820,270,220mV)$ ，周期  $(T = 2ms)$  、脉宽基本不变  $(T_{1} = 1ms)$ ，时间常数增大  $(\tau = 20,90,120\mu s)$  。

# 1、归纳连续系统基本单元的电路结构和运算功能

# （1）加法器

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/20e7b6e323fa14ed7dc8673cd20a47b89bf70a20bad3cbdbb23850bdd7adac62.jpg)

输入与输出关系：  $u_{0} = -\left(\frac{R_{f}}{R_{1}} u_{1} + \frac{R_{f}}{R_{2}} u_{2} + \frac{R_{f}}{R_{3}} u_{3}\right)$

（2）减法器

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/26b95dad9d4d2c945ca1ec5045915f4ac7f644cb55789c814fd7fb665afa74ff.jpg)

输入与输出关系:  $u_{0} = -\frac{R_{2}}{R_{1}} \left(u_{2} - u_{1}\right)$

（3）倍乘器（同相比例器）

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/70a0cdcba70f93ede47c54d21440cfb4e7c281fd9768ed4c63410b59d79bedc2.jpg)

输入与输出关系:  $u_{2} = \left(1 + \frac{R_{f}}{R_{1}}\right) u_{1}$

（4）反相器（反相比例器）

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/fecdb0fc8d7636b04dd8f6f055f6eada12fcdee5bf7e9106a3b6ec8c526dc142.jpg)

输入与输出关系:  $u_{2} = -\frac{R_{f}}{R_{1}} u_{1}$ , 当  $R_{f} = R_{1}$  时, 即  $u_{2} = -u_{1}$  实现反相功能。

（5）积分器

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/cd0e14327b9921ca620a2eeb95d762eeb2bca8848d73bc38928bb17eb985d6e7.jpg)

输入与输出关系:  $u_{2} = -\frac{1}{RC} \int_{-\infty}^{t} u_{1}(\tau) d\tau$

（6）微分器

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/956f2fbdfe098977069d2c50b4fffc113cc4eadab656a150e20d357d1732cd30.jpg)

输入与输出关系:  $u_{2} = -R C \frac{d u_{1}(t)}{d t}$

2、将下图一阶RC电路转化成由基本运算器构成的电路并画出其模拟框图

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/c5daf89d20aeed4845870bc1604afa2cb19f0a50293710ed4f58ed5201d5f5ff.jpg)

由于  $y(t) = \frac{1}{C}\int_{-\infty}^{t}i(t)dt = \frac{1}{RC}\int_{-\infty}^{t}x(\tau)d\tau$ ，由于积分电路输出信号与输入信号反相，欲模拟还需进行反相调整，故需要使用1个积分电路+1个反相器即可等效模拟一阶RC电路：

在Multisim上绘制基本运算器模拟电路：

![](https://cdn-mineru.openxlab.org.cn/result/2025-11-12/688fedef-183b-4818-903f-edc5564ee162/d8abe0e18380a0486215402541cc2b7139592033876a979b9a6cfabf13ebaeab.jpg)

当信号经过第一个积分器时：  $u_{1}(t) = -\frac{1}{RC}\int_{-\infty}^{t}u_{o}(\tau)d\tau$

再通过第二个反相器，由于  $R_{2} = R_{3}$  有：  $u_{o}(t) = -u_{1} = \frac{1}{RC}\int_{-\infty}^{t}u_{o}(\tau)d\tau$

实现了： $y(t) = \frac{1}{RC} \int_{-\infty}^{t} x(\tau) d\tau$ ，成功模拟了一阶 RC 电路。
